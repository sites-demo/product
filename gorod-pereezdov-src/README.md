# Moving town: исходники

Исходники сайта https://www.studio-sait.ru/gorod-pereezdov/ (React 19, Vite, three.js).
Собранный сайт лежит в папке `../gorod-pereezdov`, её и раздаёт GitHub Pages.
Старый адрес `/gorod-pereezdov-4/` перекидывает на основной.

## Сборка и выкладка

```
npm install
npm run build     # проверка типов, сборка, серверная сборка и пререндер в dist
npm run phones    # телефоны 320–430 px и шрифт ×1.3, все шаги расчёта, ошибки в консоли
npm run place     # копирует dist в ../gorod-pereezdov
```

Постеры 3D-сцен и картинку для соцсетей пересобирает `node scripts/posters.mjs`
после сборки, затем нужен ещё один `npm run build`.

## Тексты и админка

Тексты по умолчанию лежат в `src/site-content.json`, при сборке они встраиваются
в страницу. Админка открывается по адресу `/gorod-pereezdov/admin/` и хранит
правки в браузере (ключи `mt-v4:`), предпросмотр идёт через `?preview=1`.

## Если GitHub Pages завис

Иногда выкладка висит на статусе `syncing_files` и через 10 минут падает
по таймауту. Перезапуск такого запуска в Actions может так и остаться в очереди,
поэтому надёжнее выложить новый коммит в main.
