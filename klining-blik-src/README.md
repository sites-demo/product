# Блик: расчёт уборки квартиры

Клиент собирает свою квартиру в 3D: комнаты, санузлы, окна, балкон, кухонная техника. Видит цену сразу и отправляет заявку с фото. Мастер получает её в кабинете.

- `src/client` страница для клиентов
- `src/cabinet` кабинет мастера
- `src/lib` прайс, расчёт, работа с API

Сервер общий с калькулятором химчистки (`../himchistka-svezho-src/server`), правила расчёта для уборки повторяют `src/lib/store.ts`.

```bash
npm install
npm run dev                                   # демо, данные в браузере
VITE_API_URL=http://localhost:5080 npm run dev # с сервером
npm run build && npm run place                # сборка в ../klining-blik
```
