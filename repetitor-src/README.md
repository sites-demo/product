# Репетитор: страница с расчётом подготовки и кабинет

Родитель выбирает экзамен, текущий балл и цель, видит сколько занятий в неделю нужно и сколько это стоит в месяц, и записывается на знакомство. Репетитор получает заявку в кабинете, ведёт учеников, расписание и оплаты.

- `src/client` страница для родителей и учеников
- `src/cabinet` кабинет репетитора (заявки, ученики, цены, настройки)
- `src/lib` расчёт подготовки, данные, работа с API
- `scripts/desk.py` сцена для первого экрана в Blender (`pip install bpy==5.3.0`, затем `npm run render`), `scripts/page.py` рисует разворот тетради

```bash
npm install
npm run dev                                   # демо, данные в браузере
VITE_API_URL=http://localhost:5080 npm run dev # с сервером
npm run build && npm run place                # сборка в ../repetitor-klimova
```

Имя, телефон и тексты репетитора в `src/lib/store.ts` (`TUTOR`) и `src/client/App.tsx`.
