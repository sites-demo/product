# Ролик «Переобувка»

Исходники `v/pereobuvka.mp4`: 3D-ролик на 20 секунд с кубическими персонажами (Three.js), бит 150 BPM, озвучка ElevenLabs, 1080×1920, 30 fps. Сборка: `bash build.sh`.

Сюжет: сезон переобувки, телефон шиномонтажника прыгает по верстаку («Звонков с утра: 23 → 99+»), вопросы складываются в башню, телефон улетает в покрышку, из неё фонтаном бьют вопросы. Стоп-кадр с облётом камеры: «А можно так:». Сайт вымышленного шиномонтажа «Колесо»: цена по радиусу, свободное время, запись в одно касание. Заявка приходит с сайта. Финал с оффером и условием показа.

Вошло в ролик: первый кадр сразу в действии (стратег); «звонков с утра», а не «пропущенных», и подпись «время мастер меняет сам с телефона» (владелец); телефон в покрышку, фонтан вопросов, облёт камеры (редактор); «заявки приходят с сайта» вместо «телефон молчит», цены с пометкой «пример», условие показа, никаких логотипов мессенджеров и карт (юрист); счётчик и крупный экран сайта (моушн-дизайнер).
